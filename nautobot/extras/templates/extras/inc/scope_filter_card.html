{% comment %} Scope filter sub-form, shared by custom fields and conditional triggers. Renders the target model's own filter form under a `scope-` prefix, so its inputs cannot collide with the object's own fields. The context comes from `ScopeFilterViewMixin.get_scope_filter_context`, and the enclosing template must include `extras/inc/scope_filter_js.html`. The heading and empty-state text are defaults here rather than arguments, so every form using this component reads the same. Only pass an override when a form genuinely differs. Accepts: scope_filter_disabled_message Shown instead of the form when scoping cannot apply at all, which is specific to the including form (e.g. a required custom field). scope_filter_title Override the heading. Rarely needed. scope_filter_empty_message Override the empty-state text. Rarely needed. {% endcomment %} {% load form_helpers %}
